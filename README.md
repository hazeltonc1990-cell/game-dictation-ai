# game-dictation-ai
Created to use Speech to Text while playing Wardogs

In order for application to work properly it must be executed using the option 'Run as Administratior'
After it is open you must click "Save & Apply Settings" even if you do not make any changes. This is required so the app can apply the AI Model 'base.en' or 'tiny.en'

This app does not require an installer and will auto update from GitHub if any changes have been made.
